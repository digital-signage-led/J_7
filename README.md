# J_7 — 1920×176 LEDサイネージ（案件まとめ）

1920×176（15面）の LED サイネージコンテンツを、**案件ごとにフォルダ分け**して管理するリポジトリです。

## 案件一覧

| フォルダ | 案件 | 地点 | 備考 |
|---|---|---|---|
| [`名古屋/`](./名古屋/) | 警報情報 | 名古屋市 | 右端固定ロゴなし |
| [`磯子_エネオス/`](./磯子_エネオス/) | 神奈川・エネオス | 横浜市磯子区 | 気象9面＋ENEOSロゴ横スクロール |

## 使い方

1. 表示したい案件フォルダを開く
2. その中の `index.html` を起動（または静的ホスティングへ配置）
3. 地点・ロゴは各案件の `assets/site-config.js` を編集

## 新規案件の追加

同じ構成でフォルダを追加してください。

```
案件名/
  index.html
  assets/
    site-config.js
    …
```
